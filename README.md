# Personal CV Website

My first web project: a simple multi-page **personal CV website** built with plain **HTML**. It covers my education, work experience, skills, hobbies and contact details.

## Pages

| File | Content |
|---|---|
| `index.html` | Main CV: education, work experience and skills (uses an HTML table) |
| `contact.html` | Contact details |
| `_hobbies.html` | Hobbies |
| `input.html` | Practice page for HTML form inputs |

## Tech Stack
HTML5 (semantic tags, tables, links between pages)

## How to Run
Clone the repo and open `index.html` in any browser:

```bash
git clone https://github.com/Surupam2002/CV.git
```
